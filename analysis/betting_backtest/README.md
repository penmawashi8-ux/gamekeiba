# 「1年間〇〇を買い続けたら」検証（2025年 JRA 全レース）

「1番人気の単勝 vs 穴馬の単勝を1年買い続けたら」系の検証を、ほかの買い方にも広げたもの。
ゲーム本体（`backend/` `frontend/`）とは無関係の分析スクリプト。

## データ

- 出典: [keibamar/keiba_ai_ver3.0](https://github.com/keibamar/keiba_ai_ver3.0)（netkeiba 由来のレース結果と確定払戻を CSV で公開しているリポジトリ）
- 対象: **2025年1月5日〜12月28日の JRA 平地・障害 3,426レース**
  - 単勝: 全3,426レース。払戻表が欠けている71レースは、1着馬の確定オッズ×100円を払戻とした
  - 単勝以外（複勝・馬連・三連単など）: 払戻表がそろっている3,355レースだけで計算
- 1点100円。払戻は公式の確定配当。出走取消・競走除外の馬は買わなかった扱い（返還）
- 元データに同じレースが2回入っている箇所（福島の24レース）は重複を除いた

netkeiba・JRA 公式サイトはこの作業環境からは接続できなかったので、公開済みの CSV を使った。
2024年分は元データにほぼ入っていないため、直近で丸1年そろっている2025年を使っている。

```bash
./fetch_data.sh /path/to/keiba_ai_ver3.0     # 必要なファイルだけ取得（約100MB）
python3 backtest.py /path/to/keiba_ai_ver3.0  # results/ に CSV を出力
```

`results/累計収支_日別.csv` は日ごとの累計収支で、動画の「残高推移グラフ」にそのまま使える。

### アニメーション動画（BGM付き）

```bash
pip install pandas matplotlib               # ffmpeg と Noto Sans CJK JP（fonts-noto-cjk）も必要
python3 make_video.py jockey ninki ranking  # → videos/*.mp4
```

| 動画 | 内容 |
|---|---|
| `jockey.mp4` | 勝利数トップ3（ルメール・戸崎圭太・松山弘平）vs 回収率1位（原優介）の単勝。重賞勝ちを馬名つきで速報、G1勝ちは線に★、30倍以上の的中はカード表示 |
| `ninki.mp4` | 1番人気・2番人気・最低人気の単勝と、1→2→3番人気の三連単。100倍以上の的中をカード表示 |
| `ranking.mp4` | 300騎乗以上の騎手66人の累計収支 TOP10 が入れ替わっていくバーチャートレース。100倍以上の的中と G1 勝ちを右に速報 |

- 横 1920x1080・30fps・65秒（タイトル2.5秒 → 1年分の推移56秒 → 結果6.5秒）
- BGM と効果音は `bgm.py` がその場で合成するオリジナル（素材ファイル不要・権利フリー）。高配当で「チャリーン」、G1でファンファーレ、重賞で「キラッ」
- 重賞の判定は `grades.py` のレース名リスト（元データにグレードが無いため）。勝利数はこのデータで数えたもので、公式記録とは数勝ずれることがある（下の「外部データとの照合」参照）
- 比べる系列は `make_video.py` の `PRESETS` に足せば増やせる

## 結果まとめ

### 0. 元ネタの再現：人気別 単勝（3,426レース）

| 買い方 | 回収率 | 的中率 | 収支 | 最大連敗 |
|---|---:|---:|---:|---:|
| 1番人気の単勝 | 77.6% | 33.0% | −76,650円 | 16 |
| 2番人気の単勝 | **84.9%** | 21.1% | −51,690円 | 40 |
| 最低人気の単勝 | 43.6% | 0.3% | −193,290円 | **1,110** |
| 全頭の単勝を全部買う | 71.6% | 7.2% | −1,344,630円 | 30 |

1番人気の的中率33%・回収率78%は一般に知られている数字とほぼ一致しており、データの妥当性確認にもなっている。
最低人気が勝ったのは1年で9回だけで、1,110連敗を記録した。

### 1. 有名騎手の単勝を1年間ぜんぶ買ったら（300騎乗以上の騎手）

| 騎手 | 騎乗数 | 回収率 | 勝率 | 平均人気 |
|---|---:|---:|---:|---:|
| 原優介 | 642 | **132.3%** | 3.3% | 9.4 |
| 岩田望来 | 671 | 102.2% | 14.2% | 5.0 |
| ルメール | 513 | 74.1% | **26.9%** | 2.1 |
| 川田将雅 | 501 | 69.9% | 20.4% | 2.3 |
| 武豊 | 575 | 65.3% | 12.5% | 3.9 |
| 戸崎圭太 | 795 | 60.5% | 16.5% | 3.3 |
| 遠藤汰月 | 307 | 6.6% | 1.0% | 11.5 |

**「4回に1回勝つルメールでも負ける」「プラスになったのは無名寄りの騎手」**という逆転が起きている。
ただし原優介のプラスは279.9倍の大穴1発による部分が大きく、運の要素が強い。
全騎手の一覧は `results/04_騎手別.csv`。

### 2. 「人気どおりに決まる」に1年間賭けたら

| 買い方 | 回収率 | 的中率 | 最大連敗 |
|---|---:|---:|---:|
| 1-2番人気の馬連 | 86.2% | 17.1% | 34 |
| 1-2番人気のワイド | 81.9% | 32.9% | 20 |
| 1→2番人気の馬単 | 83.4% | 9.7% | 49 |
| 1-2-3番人気の三連複 | 78.9% | 9.3% | 73 |
| 1→2→3番人気の三連単 | 63.9% | 2.2% | 184 |
| 1-2-3番人気の三連単ボックス（6点） | 68.2% | 1.6% | 442 |

「1→2→3番人気」の完全な人気順決着は1年で74回（2.2%）しか起きない。

### 3. 誕生日馬券：「月-日」の馬連を1年間買い続けたら

- 全366通りの誕生日のうち、**19日〜31日生まれ（162通り）は該当する馬番がないので1枚も買えない**
- 買える204通りのうち、**プラスで終わったのは18通り（約9%）**
- 1位は **2月18日生まれ（2-18）で回収率1,158%**。18頭立てのレースでしか買えず252点しか買っていないところに、2,803倍が1回当たった
- 2位は2月14日（バレンタイン）で231%、3位は6月16日で207%
- 3-18、2-17、5-17、10-18 は1年間一度も当たらなかった

全誕生日の結果は `results/06_誕生日馬連.csv`。

### 4. 「毎レース◯番の単勝」— 最強の馬番は？

いちばん良かった16番でも回収率98.8%で、プラスになった馬番はなかった。最下位は5番の50.9%。
どの馬番も勝率は7%前後でほとんど差がないので、回収率の差は大穴の当たりがあったかどうかの偶然による部分が大きい。

### 5. おまけ

- 馬名の文字数別：4文字の馬（96.7%）が最もマシで、6〜8文字は65〜68%
- 性別：せん馬 84.7% ＞ 牡馬 72.9% ＞ 牝馬 68.4%

## 外部データとの照合

公開されている2025年の年間成績（主に[競馬ラボ](https://www.keibalab.jp/)の騎手別「単勝回収値」）と突き合わせた。
回収値は100円あたりの払戻なので、ここでの回収率と同じ意味。

| 騎手 | 騎乗数（ここ / 外部） | 勝利数（ここ / 外部） | 単勝回収率（ここ / 外部） |
|---|---:|---:|---:|
| ルメール | 513 / 521 | 138 / 140 | 74.1% / 74 |
| 戸崎圭太 | 795 / 805 | 131 / 132 | 60.5% / 60 |
| 松山弘平 | 826 / 836 | 126 / 128 | 90.5% / 91.0 |
| 川田将雅 | 501 / 507 | 102 / 105 | 69.9% / 71 |
| 武豊 | 575 / 575 | 72 / 72 | 65.3% / 65 |
| 原優介 | 642 / 652 | 21 / 21 | 132.3% / 130 |
| 岩田望来 | 671 / 671 | 95 / 95 | 102.2% / 102 |
| 丸田恭介 | 386 / 392 | 12 / 12 | 113.4% / 112 |
| 古川吉洋 | 483 / 483 | 27 / 27 | 100.2% / 100 |
| 和田陽希 | 329 / 329 | 11 / 11 | 105.5% / 106 |
| 藤岡佑介 | 359 / 359 | 49 / 49 | 103.5% / 104 |
| 松若風馬 | 514 / 519 | 24 / 24 | 102.6% / 102 |

- 12人中9人は回収率の差が1ポイント未満で、最大でも2.3ポイント（原優介）。勝率・人気順の傾向も一致している
- 1番人気の単勝（勝率33.0%・回収率77.6%）も、公開されている2025年の集計（勝率32.8%・回収率77%前後）とほぼ同じ
- ずれの原因は、元データに入っていないレースが数十あること（騎乗数が外部より少ない）。騎乗数が外部より少ない騎手ほどずれが大きい。
  原優介は外れた騎乗が10回ぶん欠けているので、本当の回収率は2ポイントほど低い（それでも1位は変わらない）

## 解釈するときの注意

- 1年分・1点100円のシミュレーション。騎手別や誕生日別などは点数が数百程度しかなく、**1本の大穴でプラスとマイナスが入れ替わる**。動画にする場合は「たまたま」であることも添えたほうがよい
- オッズは確定オッズ。実際には100円を足してもオッズはほぼ動かないので影響はない
